# Triage labels

For implementation issues (not wayfinder map or tickets, which carry only `wayfinder:*` labels).

| Label | Meaning |
|---|---|
| `needs-triage` | New; not yet looked at. |
| `needs-info` | Blocked on information from the reporter or owner. |
| `ready-for-agent` | Fully specified; an agent can pick it up AFK. |
| `ready-for-human` | Needs a human (device testing, signing, App Store, judgment calls). |
| `wontfix` | Will not be done; close with a reason. |

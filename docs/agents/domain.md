# Domain docs

Single context.

- `GLOSSARY.md` at the repo root: the domain language. Use its terms in code, issues and docs; avoid the terms in its "Avoid" column.
- `docs/adr/`: architecture decisions, numbered `NNNN-kebab-title.md`.
- `SPEC.md` is final for v1. Changing it needs an explicit owner decision recorded in an ADR or `TODO.md`.
- `TODO.md` holds deferred decisions; they are not in scope for v1 planning.
